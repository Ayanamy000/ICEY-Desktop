# 插件与技能

## 安装与使用

打开「05 插件与技能」，选择下面任一方式：

- **选择插件文件**：打开 `.icey-plugin.json` 或符合格式的 `.json` 文件。
- **链接或内容**：粘贴 HTTPS 文件直链，或完整的插件 JSON。下载不携带模型密钥，不跟随重定向。
- **让艾希制作**：填写想让她学会的事，生成后查看用途、所需能力和完整内容，点击「安装并启用」。生成需要连接模型。
- **从示例开始**：内附「文字整理」「文件小帮手」，无需联网即可安装；文字技能运行时需要模型。

也可以直接对艾希说：

> 帮我制作一个整理会议记录的插件，提取结论、负责人和待办。
>
> 安装这个插件：C:\example\notes.icey-plugin.json

对话提出的安装也会进入插件页供你确认。预览不会执行技能。关闭程序后未安装的草稿不保留。

插件安装后立即生效，可搜索、停用、查看内容、导出或卸载。点击技能的「使用」会打开对话并填入请求，补充文字、城市或路径后发送。也可以直接告诉艾希要用哪个技能。实际执行前，操作卡片会列出要处理的内容；文件技能会显示具体操作与路径。

已安装插件保存在 `%APPDATA%/icey-desktop-companion/plugins.json`，与启动程序分开，升级时保留。相同标识不能重复安装；更换版本前可导出旧版，再卸载、安装新版。停用或卸载后，尚未确认的技能调用将不能继续执行。

## 插件格式

这一版安装的是 **ICEY 声明式插件**：插件保存处理要求，由应用调用已有能力执行。不会把下载或生成的文字当作 JavaScript、Shell 或 Node.js 程序运行，也不支持其他软件的插件包。

```json
{
  "format": "icey-plugin/v1",
  "id": "my.notes",
  "name": "会议笔记",
  "version": "1.0.0",
  "description": "将会议记录整理成结论和待办。",
  "skills": [
    {
      "id": "summarize",
      "name": "整理会议记录",
      "description": "整理用户提供的 text，列出结论、负责人和期限。",
      "type": "prompt",
      "instructions": "保留原文事实。列出结论、待办、负责人和期限。未提及的信息标记为未明确，不编造。"
    }
  ]
}
```

文件最大 128 KB，一个插件包含 1–12 个技能。插件和技能标识长度为 2–64，使用小写字母、数字、点和连字符；技能标识在同一插件内不能重复。

| 技能类型 | 定义 | 调用输入 | 实际能力 |
| --- | --- | --- | --- |
| `prompt` | `instructions`，最多 6000 字 | `text` | 向当前模型发送处理要求和用户提供的文字，不附带历史、记忆或桌面截图，不提供操作工具 |
| `weather` | 无额外字段 | `city` | 通过内置天气服务联网查询 |
| `file` | `operation` | `source`，按操作需要提供 `destination`、`content` | 复用应用的路径检查、操作预览和确认流程 |

文件操作支持 `read`、`list`、`open`、`copy`、`move`、`trash`、`create_text`、`append_text`、`replace_text`。插件本身不保存文件路径；路径由用户在本轮对话中提供，现有文件也可以提供确切名称。读取和列目录会把内容发送给当前模型；删除移入回收站。不能通过插件跳过这些检查。当前一个文件技能只做一个文件操作，多步工作流尚未提供。

文件技能示例：

```json
{
  "id": "backup",
  "name": "备份文件",
  "description": "将 source 文件或文件夹复制到新的 destination 完整路径。",
  "type": "file",
  "operation": "copy"
}
```

技能不会自动在后台运行。定时任务仍使用内置任务处理，不会绕过确认执行插件中的文件操作。生成、识别技能和文字处理需要连接模型，可能产生服务商的调用费用。

## 内部代码扩展接口

`src/extensions/index.cjs` 的 `register(host)` 保留给项目开发者，在打包前注册经过审查的代码扩展。它与可安装的 JSON 插件不同，不受声明式能力限制，不应用来直接加载下载或生成的代码。

`host.registerPlugin({id,name,setup})` 提供 `api.registerSkill({id,name,description,run})` 与 `api.on(event,handler)`。事件包括 `task:due`、`chat:completed`、`vision:captured`；截图事件只包含时间与屏幕标识，没有图片。可安装插件不支持事件订阅。
