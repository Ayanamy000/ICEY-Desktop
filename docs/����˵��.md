# ICEY 桌面伙伴 1.0

## 开始使用

解压整个文件夹，双击「启动艾希.exe」。保留同目录的 runtime 文件夹，EXE 只是小型启动程序。升级前从系统托盘退出旧版。程序只允许一个实例，重复启动会唤醒已有窗口。

在「环境配置」连接自己的模型服务并保存密钥。所有定时任务，包括提醒和天气查询，都会调用模型；没有可用连接时会提示继续处理。部分任务需要多次模型请求，费用由所选服务计收。

## 工作区

左上角「⋯」打开管理，创建或编辑工作区，选择一个本机文件夹，再保存。保存表示授权艾希直接读写、增删该文件夹内的内容，不再逐个确认。文件内容按任务需要发送给你配置的模型，删除移入回收站并播放斩碎动画。

例如：“在工作区新建一个 notes 文件夹，写一份今天的计划到 notes/计划.md。”或者安排定时任务：“每天晚上九点读取工作区的工作记录，整理成一份日报。”任务保留自己的要求、运行结果和处理记录。

不绑定文件夹也可聊天、安排文字任务。旧版项目不会自动取得文件权限，需要自行选择文件夹并保存。解除文件夹授权后保存可停止后续文件操作；已经完成的修改不自动撤销。系统和程序目录、磁盘根目录、目录联接等不作为自动操作范围。单次运行最多十二步，复杂任务可继续处理。保留 CRT 界面、声音接口、桌面感知、插件与每周记忆回顾。

## 发布包与个人数据

此包不包含开发者的密钥、配置、对话、记忆、任务、工作区路径、安装插件或运行日志。角色动画和内置插件模板是程序资源，会随包提供。

运行后，个人数据写入当前 Windows 用户的 `%APPDATA%/icey-desktop-companion/`。在从未运行过本程序的电脑上首次启动为空白状态；在已有数据的电脑上会继续使用该电脑原有数据，解压本包不会清空它。备份时退出程序后复制整个用户数据目录。

`ICEY-Desktop-1.0.0-clean.zip` 可作为上传或分发文件，旁边的 `.sha256` 为文件校验值。无需附带开发目录或用户数据目录。

本版完成打包，按需求未运行功能测试或启动验证。
