# 记忆、项目分组与定时任务

1.0 使用内置 SQLite 数据库保存记忆、工作区、对话、任务计划和运行结果。无需安装数据库服务。

## 工作区与文件授权

左上角选择当前工作区，旁边的「⋯」进入管理。可以新建、编辑、归档和恢复项目。选择本机文件夹并保存后，授权艾希在该文件夹内直接读取、新建、修改、移动、复制和删除内容，无需逐次确认。文本读取会发送给当前模型，删除仍移入回收站。选择空路径并保存可撤销文件授权；旧版项目默认没有文件授权。

工作区根目录本身不能删除或移动。程序检查路径范围、每级父目录和递归目录内容，拒绝路径越界、符号链接、目录联接和硬链接文件。系统与程序目录、用户主目录及磁盘根目录不能授权。运行中的授权变更会停止后续步骤，已经完成的操作不会撤销。未绑定文件夹的工作区仍可用于日常对话。

每个项目保存自己的最近 100 条对话、任务、运行结果与项目经历。称呼、兴趣、交流偏好和边界共享。默认「日常」不能归档；归档项目会暂停其中的任务，恢复后需要自行启用。

## 记忆与成长

普通文字对话会记录适合回顾的用户原话。提取的记忆必须提供能在原话中找到的引用。桌面截图及读取文件后的内部请求不进入记忆提取；敏感词过滤只是辅助措施，不应将密码等作为聊天内容提交。

每周一 09:00（北京时间）整理上一周。应用未运行时，下次启动补做；没有配置模型时等待连接。可以关闭自动回顾，或在「共同记忆」中点击「现在整理」。整理会将相关原话发送给当前配置的模型服务，并可能产生额外费用。

长周记录分批处理，已完成的批次保存在本机，失败后重用。自动整理每轮最多发起六次请求；没有记录的周不会调用模型。原始事件保留 180 天，旧聊天不会追溯补入回顾。周报总览展示所有工作区最近 16 份回顾；对话只引用当前项目对应的回顾内容。

明确偏好可直接记录，观察到的习惯必须有至少两个不同日期的依据，90 天未更新后不再用于回复。表达倾向每项每天最多变化两点，保留艾希感谢、自主、尊重和诚实的核心。成长是本地记忆影响回答，不是重新训练模型。

可以搜索、按类型筛选、修改和删除记忆。修正或删除会清理相关回顾依据，避免旧依据再次生成同一条记忆；有关周报也可能被移除。删除一份周报会清理该周所有工作区的原始依据，已提取的记忆仍保留。重置记忆清空全部工作区的记忆与回顾，对话和任务保留；清空聊天则只清除当前组的近期对话。

## 定时任务

每个任务包含名称、每次执行的要求、所属工作区、时间与重复方式。可以选择独立执行，或在文字任务中接着上次成功的结果继续。立即运行不改变原有安排；任务按队列逐个处理，运行状态和结果单独保存，避免把“计划已到期”误认为“工作已成功”。

结果区展示当前组最近 100 次执行，区分等待、运行、成功、失败和需要处理；未读结果有标记。展开结果会标记已读。「继续处理」把原任务带回对话输入框，方便补充信息并确认操作。

所有任务都会调用模型理解要求，包括仅提醒和天气任务。模型按需查询天气、读写授权工作区文件或使用已启用技能，再根据工具结果回复。每次最多十二步、三分钟；结果保存实际操作记录，失败或中断前已经完成的操作不会撤销。仅提醒模式依然调用模型，但不允许文件修改。缺少资料、文件授权、模型连接或外部软件能力时需要继续处理，不提供任意脚本执行。

单个文本文件读取上限 256 KB，向模型提供前 16000 字符并标记截断，目录列表最多 200 项；目录整体复制、移动、删除最多检查 5000 个节点。写入使用完整文本而非差异补丁。定时任务不是后台云服务，须保持应用和电脑运行。锁屏或休眠时暂停；普通错过任务补办一次，「只在」指定日期的任务过日后不补办。

## 数据与升级

数据位于 `%APPDATA%/icey-desktop-companion/`：

- `memory.sqlite`：记忆、原始事件、周报、项目、每组对话、任务与结果。
- `state.json`：环境配置、经系统加密的密钥。
- `plugins.json`：安装的插件。

首次升级将旧版记忆、对话和任务迁入数据库，旧对话及任务归入「日常」。数据库文本未单独加密，不上传备份。备份前先从托盘退出程序，再复制整个用户数据目录；运行时可能还有 `memory.sqlite-wal` 和 `memory.sqlite-shm` 文件。

实现参考 [Node.js SQLite 文档](https://nodejs.org/api/sqlite.html)。定时任务交互参考 [Codex 自动化文档](https://learn.chatgpt.com/docs/automations?surface=app) 中的独立执行、上下文衔接和结果收件箱思路，本应用的执行能力仍以已实现的工具为限。

本版本按用户要求未运行测试或启动验证。
